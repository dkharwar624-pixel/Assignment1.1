When a user types a URL in the browser, the Browser which is the Client requests the IP address of that URL from DNS and then sends a request to the Server using HTTP (HyperText Transfer Protocol) and HTTPS (HyperText Transfer Protocol Secure) which is the secure version of HTTP with SSL/TLS encryption. This is called the Request-Response Cycle where the client sends a request and the server processes it, fetches data from the Database if required, and sends back a response containing the website files (HTML, CSS, JS) which the browser then renders on the screen. If the website is Static, it shows the same fixed content to everyone without using a database, whereas a Dynamic website shows personalized content by using a database. This entire request-response process can be seen live in Chrome DevTools under the Network tab.Submission Screenshot Step: Chrome > Any Website > Press F12 > Network Tab > Reload > Take Screenshot [You will see Status 200 and file types like document, stylesheet, script]
